# PROLOAG Web Demo

学習の計画・実績・知識と、生活・健康の記録をつなぐPROLOAGの閲覧用展示版です。
架空の180日分（2026年5月10日〜11月5日）を使い、計画・分析・可視化をブラウザで体験できます。

**このパッケージはWeb展示用の作成・検証済みソースです。Community Cloudへの配置や一般公開はまだ行っていません。**

## まず見る画面

1. **はじめに** — アプリの目的と架空データの規模。
2. **学習ロードマップ** — 9工程・2つの節目をガントで俯瞰。検索、工程の詳細、全体／月／週の切り替え。
3. **学習の分析** — 期間や表示条件を変えて、勉強時間と学習の傾向を確認。
4. **学習の蓄積・知識都市** — 学習銀河・学習の航跡・クリスタル標本や知識都市で積み重ねを可視化。
5. **生活・健康の分析** — 睡眠・体調・運動と学習の記録を日付で確認。

保存・削除・アップロード・外部サービス接続は提供しません。
表示条件は訪問者ごとに独立し、元の架空データは変わりません。CSVは架空データのみです。
個人の記録を入力・保存する用途には使いません。

## ソースの構成

- main.py / web_demo/ — 展示専用の入口、許可された7画面、閲覧用ガント、固定データの検証。
- reference_pages/ — 元アプリのページ。4つの分析・可視化画面だけを展示の許可リストから呼び出します。
- app_core/ / prolog_ui/ — アプリ本体の集計・表示部品。展示コピーでは保存層に書き込み拒否を加えています。
- web_demo/dataset_manifest.json — 架空データ715ファイルの由来・SHA256。起動時に整合を確認します。
- tests/test_web_demo_*.py / scripts/verify_web_demo.py — 展示版の検証。
- UPSTREAM_SOURCE_MANIFEST.json — 変更前の公開用ソースの参照記録。現在の展示版のハッシュ一覧ではありません。

元のローカル版の入口は [参照用ソース](docs/local-main.py.txt)、元の説明は [参照用README](docs/local-source-readme.md)に残しています。
これらの通常版向けセットアップや保存・編集テストは、この展示版の起動・検証には使いません。

Linuxと実際のCommunity Cloud上のビルド・画面確認は、ローカル検証とは別途必要です。
