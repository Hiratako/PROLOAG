# Web体験版の検証記録

2026年11月7日に、Hobby & Toolsを除くWeb体験版をローカルのWindows環境で検証しました。通常版の主要25ページに、はじめに・説明を加えた27ルートが対象です。

## 結果

**63種類のテストを対象に、62種類が成功、1種類をスキップしました。失敗・エラーは0件です。**

同じテストを重複して数えないよう、以下の3回の実行を合成しています。

| 実行 | 対象 | 件数 | 結果 |
|---|---|---:|---|
| 画面・操作・保存の広範な確認 | 既存の境界・表示回帰37件、保存領域12件、操作ワークフロー8件 | 57 | 失敗・エラー0、スキップ1 |
| レビュー後の保護処理確認 | 保存領域13件、Google接続境界4件 | 17 | 失敗・エラー0、スキップ1 |
| リセット表示の回帰確認 | 実際のmain画面でデータと確認チェックの初期化を確認 | 1 | 成功 |

実行件数の合計は75件ですが、最初の2回で12件が重複しているため、異なるテストは63種類です。2回のスキップは、どちらも同一のシンボリックリンク検証です。Windowsの実行アカウントにリンク作成権限がなかったため、実リンクによる試験は行えていません。パス逸脱や別利用者へのアクセス拒否は別のテストで確認しました。

環境は **Windows / Python 3.11.4 / Streamlit 1.57.0** です。実行条件・結果・検証した保護処理のSHA256は、[機械可読の検証記録](../WEB_DEMO_VERIFICATION.json)に記載しています。公開用の記録には個人の絶対パスや生ログを含めていません。

## 再実行

依存ライブラリを導入したPython 3.11環境で、次を実行します。

```powershell
python scripts/verify_web_demo.py
```

`test_web_*.py`を検出するため、今後テストが追加された場合の件数は、この記録と異なることがあります。レポートの出力先として共通データやマニフェストを指定した場合は、実行前に拒否します。
