# PROLOAG {{VERSION}}

配布基準日：2026年11月5日／対象：Windows x64

通常版と中小企業診断士Demo版を、同じアプリコード・Python 3.11・基本依存定義から配布するPreview版です。配布物の識別と内容のハッシュは `RELEASE_MANIFEST.json` を参照してください。

## 主な収録機能

- 今日の記録・計画、秒給カウンターと時間の小窓、勉強ログの追加・編集・復元。
- 学習ロードマップ、工程・節目・日別配分、AI計画JSONの取り込み。
- ノート・カード・復習、学習蓄積や生活・条件の可視化、統計演習。
- 日記、服薬・カフェイン、睡眠・体調、運動の記録。
- 全記録CSV・ZIP、任意のGoogle共有・相談レポート、旧版ログ移行、整合性チェック。
- MP4→MP3、日本語・英語の文字起こし、画像・PDFの文字読み取り。これらの任意機能には追加準備が必要です。

通常版の記録は空です。Demo版は架空180日分と固定日2026年11月5日、少量の架空ロードマップを収録します。

## 利用前に確認すること

- 初回の基本ライブラリ導入はネット接続が必要です。FFmpeg、ASR/OCRの専用依存・モデル、Google認証情報は同梱していません。
- 保存場所は配布内の `app/` です。自動更新・アプリ全体のCSV一括復元はありません。
- 小窓は対応するChrome／Edge向けです。ブラウザや環境によって利用できない場合があります。
- 集計・条件比較は記録上の傾向を示します。時間や件数は理解度そのものではなく、相関は因果関係を確定しません。

## このPreview版で把握している制限

- 睡眠・体調の未記録日に初期値のサマリーが出る場合があります。手動勉強ログは未操作の条件初期値も保存するため、条件欄を確認して記録してください。
- 同じ日の睡眠・体調記録を複数画面から同時に編集すると、元画面の未保存入力が保持されないケースがあります。同日記録の並行編集を避け、保存後に内容を確認してください。
- 一部の自動計算表示は、入力直後には更新されず保存時に再計算されます。
- 設定の初期時給0・初期運動時間0は再表示が別値になる場合があります。不正な時刻が初期値に置き換わる場合もあるため、保存後の値を確認してください。
- ノートのMarkdown出力は保存済み内容です。入力中の変更を含めたい場合は、本文・タイトル等を保存してから出力してください。
- 保存済みカードや運動記録など、画面からの編集方法がそろっていない部分があります。
- ロードマップの俯瞰は多数工程で縦に長くなり、複数段の期限マーカーの対応にも改善余地があります。工程の詳細日付で確認してください。
- 一部ページ間では日付・選択対象・集計期間を引き継がず、移動先で選び直す必要があります。

既知の制限を含む試用版として配布します。配布時の確認範囲・追加テストの結果は、同梱される検証記録がある場合はその内容を参照してください。実際のGoogle認証・送信や、すべての音声・教材の認識結果を保証するものではありません。
