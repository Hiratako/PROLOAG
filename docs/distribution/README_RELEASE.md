# PROLOAG 通常版

{{VERSION}}／2026年11月5日基準／Windows x64

自分の学習・知識・生活の記録を、空の状態から始める版です。Demo版と同じアプリ機能を利用できます。起動手順は `README_FIRST.md` を確認してください。

## 初期状態

- 学習ログ、日次計画、日記、睡眠・体調、運動、ノート、カード、復習履歴は空です。
- 個人記録・個人設定・Demoの架空履歴・Google認証情報は含みません。
- 分類にサンプルがある場合は、使い始める前に「マスタ管理」で自分の内容へ変更できます。
- 「今日」はPCの日付を使います。Demoの固定日は設定していません。

## 最初の使い方

1. 「使い方ガイド」で、使いたい機能の入口を確認します。すべての機能を設定する必要はありません。
2. 「マスタ管理」で、プロジェクト・科目・教材などを準備します。
3. 「ユーザー設定」で、入力の初期値と表示するページを調整します。
4. 「今日の記録・計画」でタスクを作り、「秒給カウンター」または「勉強ログ」で記録します。
5. 記録がたまったら、学習・生活のダッシュボードで振り返ります。

記録がない間は、グラフや分析が空のページがあります。ロードマップも自分の工程を登録して使います。

## 保存場所

学習・生活の記録、ノート、分類、設定は、この配布フォルダの `app/` 内に保存されます。文字起こし・OCRを利用した場合は、入力コピーや結果も同じ `app/` 内の専用領域に残ります。元の動画・教材ファイルへのリンクは、元ファイルを別途保管してください。

バックアップするときは、処理とアプリを終了してから配布フォルダ全体をコピーします。更新は `UPDATE_GUIDE.md` の手順で行い、新しいZIPを上から展開しないでください。

「データエクスポート」のCSV・ZIPは一覧・集計用です。記録の追加・編集後は生成日時を確認し、必要に応じて生成・更新してください。CSVを一括取り込みしてアプリ全体を復元する機能ではありません。

## 任意機能

メディア変換、文字起こし、OCR、Google連携は追加準備が必要です。各ページと `app/docs/` の案内を確認してください。専用エンジン・モデルは必要な機能だけ導入できます。
