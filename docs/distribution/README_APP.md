# PROLOAG

Progress & Reflection OS for Learning, Organization, And Growth

今日の記録を、次の物語へ。

PROLOAGは、学習計画・計測・ノート・復習と、生活コンディションの記録をまとめるローカルアプリです。これはWindows x64向け **{{VERSION}}** の配布内ガイドです。

## 起動と保存

配布フォルダ直下の `PROLOAG.exe`、または `起動する.bat` から起動します。Python 3.11本体を同梱し、初回のみネット経由で基本ライブラリを準備します。通常版は8502、Demo版は8503を使います。

利用するポートが使用中なら、配布用の起動ファイルは起動を止めて案内します。別のアプリへ自動接続せず、既存アプリを終了しません。利用中の版で保存・終了してから起動し直してください。

記録はこの `app/` 内に保存します。配布ルートの `README_FIRST.md` と、通常版の `README_RELEASE.md` またはDemo版の `README_DEMO.md` を先に確認してください。更新前はアプリを終了してバックアップし、新しいZIPを使用中のフォルダへ上書きしないでください。手順は配布ルートの `UPDATE_GUIDE.md` にあります。

## 使いたいことから始める

- 日々の実行：今日の記録・計画、秒給カウンター、勉強ログ。
- 中期計画：[学習ロードマップ](docs/study-roadmap.md)。
- AIが作った計画：[取り込み手順](docs/roadmap-ai-import.md)、[GPT／Geminiに渡す指示書](docs/ai-roadmap-import-prompt.md)。
- 知識の整理：ノート・知識ベース、記憶フラッシュ、復習リマインダー。
- 生活記録：日記、服薬・カフェイン、睡眠・体調、運動。
- 振り返り：学習・生活のダッシュボード、蓄積ビジュアライザー、条件分析、統計演習。
- 旧記録の移行：[旧版勉強ログの取り込み](docs/legacy-study-import.md)。

アプリの「使い方ガイド」には初期設定から保存・修正までの案内があります。使う機能だけを選んで始められます。

## 追加準備が必要な機能

- [MP4→MP3](docs/media-conversion.md)：FFmpeg／FFprobeを準備します。
- [文字起こし](docs/transcription.md)：FFmpeg、専用エンジン、認識モデルを準備します。
- [画像・PDFの文字読み取り](docs/ocr.md)：専用エンジン・モデル等を準備します。
- [Google Sheets共有](docs/google-sheets-setup.md)、[Google Docs相談レポート](docs/google-docs-reports.md)：任意の追加依存と自分のGoogle設定・認証が必要です。
- [相談提案の取り込み](docs/consultation-proposals.md)：内容を確認して手動で反映します。

専用エンジン・大型モデル・Google認証情報は配布ZIPに含みません。初回モデル取得にもネット接続と保存容量が必要です。
