# PROLOAG 中小企業診断士Demo版

0.1.0-preview.1／2026年11月5日基準／Windows x64

中小企業診断士・ビジネス英語を題材に、学習・知識・生活の機能を体験する版です。学習・生活・服薬等の記録はすべて架空で、開発者の個人記録やGoogle認証情報は含みません。起動手順は `README_FIRST.md` を確認してください。

## Demoの設定

- 180日分の架空の学習・日次計画・日記・睡眠体調・運動・ノート・カード・復習予定などを収録しています。
- Demo内の「今日」は **2026年11月5日** に固定しています。後日開いても同じ時点の表示を体験できます。
- 学習ロードマップには、少量の架空工程・節目・日別連携のサンプルを用意しています。
- 起動先は `http://localhost:8503/` です。通常版の8502とは分けています。
- 通常版と同じ機能で入力・編集・保存を試せます。保存先はこのDemoの `app/` 内です。

試験・節目はDemo用の例で、実際の試験日程ではありません。服薬・カフェイン等の量も表示確認用で、推奨量を示すものではありません。

## おすすめの確認順

1. 「今日の記録・計画」で、その日のタスクと生活記録を確認します。
2. 「学習ロードマップ」で、数週間の工程・進捗・節目を眺めます。
3. 「秒給カウンター」を短く動かし、架空タスクを選んで保存してみます。
4. 「学習蓄積ビジュアライザー」「生活・健康ダッシュボード」で履歴を確認します。
5. 「ノート・知識ベース」「記憶フラッシュ」「復習リマインダー」を試します。
6. 「データエクスポート」で、生成日時を確認してCSV・ZIPを取得します。

「使い方ガイド」と「Google連携ガイド」は、接続設定なしで読めます。実際のGoogle送信には自身の設定・認証が必要です。

## 最初からやり直す・人へ渡す

**未使用の元ZIPを、別の新しいフォルダへ展開してください。** 使用中のDemoに上書きしたり、通常版へDemoデータをコピーしたりしないでください。

入力した個人情報はDemo内にも保存されます。ほかの人へ渡すときは、使用済みフォルダではなく未使用の元ZIPを使ってください。通常版や開発用アプリの記録は、このDemoの編集では変更されません。

## 追加準備と制限

MP4→MP3、文字起こし、OCRは、エンジンやモデルの追加準備が必要です。これらの大型モデル・自分の音声や教材・認識履歴は含みません。各ページと `app/docs/` の案内から必要な機能だけ導入できます。

複数のDemoを同じポートで同時に使う構成ではありません。8503番が使用中なら、この版の起動ファイルは起動を止めて案内します。既存の画面へ自動接続したり、既存アプリを終了したりしません。利用中のDemoで保存・終了してから起動し直してください。

既知の制限は `RELEASE_NOTES.md`、更新・保管は `UPDATE_GUIDE.md` を参照してください。本体の公開ライセンスは未確定のため、`LICENSE_STATUS.md` を確認してください。
