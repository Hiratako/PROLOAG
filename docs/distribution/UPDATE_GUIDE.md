# バックアップと更新

PROLOAG {{VERSION}}

**新しいZIPを、記録を付けたフォルダへ上書き展開しないでください。** 通常版の空データやDemoの架空データで、使用中の記録を上書きするおそれがあります。この版には自動更新・一括移行の操作はありません。

## バックアップ

1. 入力を保存し、変換・文字起こし・OCRを完了または中止します。
2. 起動コンソールで Ctrl+C を押してアプリを終了します。別画面・別プロセスで処理が続いていないことも確認します。
3. `app/`、`runtime/`、起動ファイルを含む、**配布フォルダ全体**を別の場所へコピーします。

バックアップには個人記録と、利用していれば認証情報や教材・音声のコピーも含まれます。自分の保管用として扱い、公開・再配布しないでください。外部フォルダに置いた教材・音声やリンク先のファイルは、別途保管してください。

## 新版を試す

1. 旧版のバックアップを残します。
2. 新版ZIPを、旧版とは別の新しいフォルダへすべて展開します。
3. 旧版を終了した状態で新版を起動し、版・起動元・通常版／Demo版の区別を確認します。
4. 動作を確認してから、必要な記録の移行を検討します。旧フォルダは、移行結果を確認するまで残します。

通常版の新規利用なら、そのまま記録を始められます。Demoを最初から試す場合も、元ZIPを新しい別フォルダへ展開すれば戻せます。

## 記録の移行を行う場合

互換性を確認し、両アプリと処理を終了してから行います。コードやPythonランタイムを旧版から一括で戻さず、データの対象を選びます。

- 主な記録：`app/study_logs/`、`daily_plans/`、`diary_entries/`、`health_logs/`、`exercise_logs/`、`notes_data/`、`master_data/`、`statistics_practice/`、`flashcards.json`、`reminders.json`。
- 設定やロードマップ：`app/settings/` 内の各設定。内容と用途を確認して選び、Demoの固定日設定を通常版へ移さないでください。
- 文字起こし・OCRを利用した場合：`app/transcription_data/`、`app/ocr_data/` の原本コピーと履歴。

設定や認証情報を一括コピーしてよいとは限りません。別PC・別WindowsユーザーではGoogle認証をやり直す必要がある場合があります。判断できないファイルは旧版に残し、元の記録を削除せずに確認してください。

起動後は代表的な日付・ノート・設定・ロードマップを確認し、「データ整合性チェック」も利用します。移行先で正しく読めることを確認するまで旧版を削除しないでください。

「データエクスポート」のCSV・ZIPは一覧・分析用です。アプリのすべての状態を取り込んで戻す完全復元機能ではありません。
