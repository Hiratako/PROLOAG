# PROLOAG はじめにお読みください

バージョン：{{VERSION}}／配布基準日：2026年11月5日

Windows x64向けのローカルアプリです。Python 3.11本体を同梱しています。Pythonを別途インストールする必要はありません。

## 起動する

1. ZIPを、書き込み可能なフォルダへ**すべて展開**します。ZIP内から直接実行しないでください。
2. `PROLOAG.exe` をダブルクリックします。起動できない場合は `起動する.bat` を使います。
3. **初回はインターネット接続が必要です。** ライブラリの準備に数分かかる場合があります。準備中のPowerShell画面は閉じずに待ちます。
4. 準備完了後にブラウザが開きます。次回からは導入済みのライブラリを再利用します。

| 種類 | 起動先 | 最初に読む案内 |
|---|---|---|
| 通常版 | `http://localhost:8502/` | `README_RELEASE.md` |
| Demo版 | `http://localhost:8503/` | `README_DEMO.md` |

この版の起動ファイルは、利用するポートがすでに使用中なら起動を止めて案内します。別フォルダのアプリへ自動接続せず、既存のアプリも終了しません。利用中の版で入力を保存し、自分で終了してから起動し直してください。

終了するときは、処理中の変換・認識を完了または中止し、入力を保存してから起動コンソールで Ctrl+C を押します。ブラウザを閉じただけではアプリが動作を続ける場合があります。

## 記録と更新

記録は、この配布フォルダ内の `app/` に保存されます。使用後のフォルダには日記・体調・学習などの個人情報が残ります。ほかの人へ渡すときは、未使用の元ZIPを使ってください。

**新しいZIPを使用中のフォルダへ上書き展開しないでください。** 初期データで記録を上書きするおそれがあります。更新時は `UPDATE_GUIDE.md` を確認してください。CSV・ZIP出力は完全復元用のバックアップではありません。

## 追加準備が必要な機能

- MP4→MP3：FFmpeg／FFprobeが必要です。
- 文字起こし：FFmpeg／FFprobe、専用エンジン、モデルの取得が必要です。
- OCR：専用エンジン・モデル等の準備が必要です。
- Google連携：任意の追加ライブラリと、自身のGoogle設定・認証が必要です。

これらの大型エンジン・モデルやGoogle認証情報は同梱していません。手順は各ページと `app/docs/` にあります。基本の記録機能は、これらを設定せずに使えます。

## 起動できないとき

- 初回のネット接続、展開先の書き込み権限、ZIPの全展開を確認します。
- 起動コンソールのメッセージと `logs/` の起動ログを確認します。
- ポート使用中の案内が出た場合は、すでに利用しているアプリを確認します。必要な記録を保存し、自分で終了してから起動し直します。
- Preview版の既知の制限は `RELEASE_NOTES.md` を確認してください。
