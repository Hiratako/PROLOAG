# 旧版ログ移行

旧式秒級カウンターで出力したセッションCSVを、元ファイルを残して現在の勉強ログへ移行します。Administrationの「旧版ログ移行」から開きます。

1. 「セッション明細CSV」に旧版のstudy_sessions CSVを選択します。study_daily_summary CSVがあれば「日次集計CSV」に選択します。
2. 「ファイルを診断」で、件数・期間・時間・金額・要確認の行・日次集計との一致を確認します。日次集計は照合専用です。
3. 「分類を対応させる」で旧カテゴリに対応する登録済みプロジェクト・科目・教材・単元を選びます。未設定でも取り込めます。新しい分類が必要ならマスタ管理で用意します。
4. 取り込まない行を選び、注意の内容を確認した行だけ「内容を確認し、そのまま取り込む要確認行」に指定します。未確認の行は保留します。
5. 「既存記録と照合して変換プレビュー」を押します。候補・確認待ち・登録済み候補・エラー・対象外を確認します。既存ログとの類似が見つかった行を確認済みにする場合は、もう一度プレビューを作り直します。
6. 必要なら判定結果CSV・現行形式への変換コピーをダウンロードします。ここまではアプリの保存記録を変更しません。
7. 内容を確認してチェックを入れ、「バックアップして取り込み候補を反映」を押します。保存直前に競合を検査し、候補だけを追加します。

ファイル・分類・対象行・確認済み行を変更すると古いプレビューでは保存できません。プレビューの再作成後は、確認チェックも入れ直します。

## 保持する内容

小数秒を含む実時間、旧時給、旧換算金額、メモ、判読できる条件を保持します。現在の残業設定による再計算や、既存ログの金額修正はしません。入力・出力区分が不明な場合は旧値を来歴に残し、現行の区分は未設定にします。

睡眠の旧区分は区分のまま保持し、正確な睡眠時間を推測しません。日別の睡眠・体調ログも自動生成しません。元CSVの行・数値文字列・変換元のハッシュを来歴として残します。旧PCの絶対保存パスは、新しい記録へ持ち込みません。

元CSVは上書きしません。ダウンロードする変換コピーは確認用で、現在のCSVエクスポートを何でも復元する機能ではありません。

## 重複と保留

元CSV内の完全一致、時間帯の重なり、既存記録との一致・類似を分けて確認します。時間帯の重なりは自動で時間を引いたり削除したりしません。登録済みと判断した行は再追加せず、判断が必要な行は確認待ちになります。

取り込み履歴を `settings/legacy_study_imports.json` に保持します。同じCSVの再送や並べ替え、取り込み後のメモ・分類変更、削除後の再送でも、同じ元記録を自動で復活させません。元CSVの内容自体を変更した場合は別途確認が必要です。

## バックアップと失敗時

反映時には `backups/json_operations/<操作番号>/transaction.json` に変更前のデータを退避します。通常の途中失敗は変更前へ戻します。アプリ終了等による未完了操作が残った場合は、サイドバーの「保存操作の復旧」を確認してください。

確認後に別の記録更新があれば、古い状態を上書きせず反映を停止します。プレビューを作り直してください。この機能に完了済み取り込みの一括取消はありません。取り込んだ記録の個別修正・削除は勉強ログで行います。

対応は旧版の所定列を持つCSVに限定します。各CSVは10MBまで、セッション明細は10,000件までです。元CSVを失わないよう保管してください。
