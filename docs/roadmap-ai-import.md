# GPT／Geminiで作った学習計画の取り込み

学習ロードマップの「AI計画の取り込み」から、JSONファイルにある新しい工程と試験・節目を一括追加できます。生成AIのAPI接続は不要です。

## 使う流れ

1. 「学習ロードマップ」→「AI計画の取り込み」でAI用のmd指示書をダウンロードします。
2. GPTまたはGeminiにそのmdを添付し、目標、開始日、期限、教材・範囲、学習可能時間などを伝えます。
3. AIからダウンロードした `学習計画.json` をアップロードし、ファイルを確認します。指示書のmdやチャットの文章ではなく、AIが出力したJSONを選びます。
4. AIが指定した分類名と既存マスタの対応を確認します。不明・曖昧な分類は適切な既存分類を選ぶか、未設定を明示的に選びます。分類マスタの自動作成は行いません。
5. 追加内容とガントのプレビューを確認し、問題がなければ「この計画を追加する」を押します。

ダウンロードするmdは静的な指示書で、個人の勉強・健康記録や分類マスタを自動で含めません。取込用の形式は [AIへの指示書](ai-roadmap-import-prompt.md) に記載します。画面から得られるJSONサンプルはすべて架空の値で、実際の計画を示しません。

## 対象と確認

UTF-8の純粋なJSON、最大2MiB、工程500件・試験／節目100件までです。少なくとも1件が必要です。日付は1900〜2199年、予定時間は整数の分数です。前提工程は同じファイル内で参照し、前提の終了翌日以降に開始する必要があります。日付・期限・進捗の矛盾、前提の循環、存在しない参照、未知のキー、JSONキーの重複などは反映前に検査します。

ファイル確認・分類選択・プレビュー・ダウンロードだけでは計画を保存しません。条件を変えた場合は、その内容でプレビューを作り直してから反映します。エラーの場所と内容を確認し、必要なら画面の修正依頼文をAIへ渡してJSONを再生成してください。

既存分類はプロジェクト→科目→教材→単元の所属を確認します。同じ名称が複数ある場合や未登録の場合は、自動的に別の分類を決めず、ユーザーの選択を必要とします。

## 重複・保存・履歴

同じ内容の再送は取込台帳と来歴で検出します。ファイル名やJSONの整形・順序だけの変更による二重追加を防ぎます。既存データと同名の候補（全角・半角、英字の大文字・小文字、前後の空白の違いを含む）は、別件として追加するか確認を求めます。名前が一致しただけで上書きしません。内容の意味が似ている計画をすべて検出する機能ではありません。

確定時には計画・分類マスタ・取込台帳の変更を再確認します。プレビュー後の別更新と衝突した場合は保存せず、入力を保持して再確認を案内します。工程・節目と取込履歴を同じ保存操作にまとめ、変更前の内容を `backups/json_operations/` に退避します。途中失敗は既存の保存操作の復旧に対応し、同じ操作の再試行では二重追加しません。

計画の正本は `settings/study_roadmap.json`、取込履歴・再送防止台帳は `settings/roadmap_imports.json` です。既存工程の不明な追加項目、当初予定・変更履歴、日別割当を保持して、新しい工程・節目のみ追加します。取込後に工程を編集・削除しても、同じ取込元の内容を再送して復活させる扱いにはしません。

全件CSV／ZIPの設定原文には取込台帳も含めます。これは内容を保持するための出力で、一括復元機能ではありません。

## 第一段階の範囲

登録済み工程の更新・削除・一括置換、日別タスクや学習可能時間設定の取り込み、完了済み取込の一括取消は対象外です。工程を取り込んでも日別タスクは自動作成されません。必要に応じて既存の「学習可能時間・配分」や「日別タスクとの連携」を使ってください。

この検査はファイルと計画の整合性を確認するもので、学習効果や予定通りの完了を保証するものではありません。学習可能時間と日別予定に対する実際の配分は、既存の負荷確認画面でも確認できます。
