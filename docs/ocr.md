# 画像・PDFの文字読み取り

Hobby & Tools → **画像・PDFの文字読み取り** で、日英の教材を文章にできます。日本語・英語・日英混在は同じ多言語モデルで読み取ります。

## 使い方

1. JPEG／PNG／PDFをアップロードするか、PC内のフルパスを入力し、**ファイルを確認** を押します。
2. 読み取りページを `1-3,5` のように指定します。1回100ページまでです。
3. 必要に応じて「回転・読み取り範囲を指定」を開き、設定するページと右回りの角度を選びます。
4. **プレビューを表示** し、画像をドラッグして **選択範囲を適用** を押します。適用済みの範囲を下の表示で確認できます。数値の範囲指定も使えます。
5. 読み取り方法を選び、**読み取りを開始** を押します。原本コピーの保存後、別プロセスで処理が進みます。別ページへ移動しても続行します。
6. 完了後、ページと文章を選び、原本を見ながら修正します。画像内の文章領域を選んで編集対象を切り替えることもできます。
7. **修正を保存** で確定し、TXT／Markdown／JSONを取得します。出力には読み取りを完了した全ページの保存済み文章を含みます。

範囲は回転後のページに対する割合です。角度を変更すると、そのページの範囲を全体へ戻します。ページごとの設定は「今回の設定を確認」で確認できます。入力や回転の変更だけでは再解析・再認識せず、プレビューも明示操作で作成します。

## PDFの読み取り方法

- **自動**：回転や切り出しをしていないページに既存の文字がある場合、その文字と位置を抽出します。文字を抽出できないページはOCRへ進みます。
- **画像としてOCR**：既存文字に関係なくページ画像を読み取ります。写真や図の中の文章が残るPDF、既存の文字層が誤っているPDFで使います。
- 回転・範囲指定をしたページ、PDF内の回転設定があるページは、画像として読み取ります。

PDFに文字が一部だけある場合、自動抽出では画像部分の文章が含まれないことがあります。そのページを「画像としてOCR」で読み直してください。PDFの元ページ番号を履歴・出力へ残します。

## 照合と修正

PCでは左に原本、右に編集欄を表示します。狭い画面では縦に並びます。画像は画面内に収め、選択中の文章領域を強調します。OCRスコアが0.8未満の箇所は黄色で目印を付けます。スコアは確認順を決める参考情報で、文章の正しさを保証する値ではありません。

原文・ページ・位置・認識スコアを残して、文章だけを修正します。修正は独立したロックとrevision照合で競合を検出します。競合・書込失敗では下書きを保持して保存を止めます。未保存の修正はブラウザーセッション中に保持するため、再読込・アプリ再起動前に保存してください。

TXTはUTF-8 BOM付き、Markdown／JSONはUTF-8です。TXT／Markdownは保存済みの文章、JSONは原文と修正後、元ページ番号、位置、回転・範囲、処理状態、原本コピーのSHA256を含みます。JSONの位置は回転・切り出し後の作業画像に対する0〜1の座標です。ダウンロードで認識を再実行しません。

## セットアップ

起動中アプリと同じPythonを使うコマンドをページ下部に表示します。

```powershell
& '<アプリの起動用python.exe>' -B '<アプリの場所>\app_core\setup_ocr.py'
```

専用の `.deps-ocr311`（Python 3.11の場合）へRapidOCR 3.10.0／ONNX Runtime／pypdfium2／Pillowを導入します。アプリ本体や音声文字起こしの依存とは分離し、別プロセスだけで利用します。CPUでPP-OCRv6 small系モデルを使います。

認識モデルは最初のOCR時に公開配布元から `tools/ocr-models` へ取得し、取得後はPC内で認識します。画像・PDFを外部APIへ送信する処理はありません。ページを開くだけでは追加の導入やモデル取得を始めません。

## 保存・中止・容量

- アップロード200MBまで、PC内ファイルの直接指定は1GBまで。画像は4000万画素以内、PDFは1〜10000ページ、選択は1回100ページ以内です。パスワード保護PDFは対応しません。
- 原本は変更せず、開始時に `ocr_data/jobs/<ID>/` へコピーします。結果の原本表示はコピーから作成するため、元ファイルを移動しても完了した履歴を開けます。
- PDFは1ページずつ描画し、画像の長辺を2400px以内にして認識します。プレビューは長辺1200px以内です。
- 履歴・原本コピー・ページの認識結果・修正は再読込やアプリ再起動後も残ります。履歴を削除すると、その履歴専用のコピーと結果・修正を削除します。元のローカルファイルは削除しません。
- **読み取りを中止** でモデル準備中や認識中も停止できます。完成したページを順次保存し、中止・途中エラー・プロセス終了では完成済みページを保持します。処理途中のページは結果に含めません。
- 中止・失敗後は元ファイルを指定して新しい履歴として再実行します。未完了ページからの自動再開は行いません。
- OCR同時実行は1件、処理上限12時間、1履歴の保存容量は2GBを目安の上限とします。空き容量を開始前に確認します。
- 学習記録の `backups/json_operations` ロックは取得しません。OCR用の独立したロックとatomic replaceで保存します。

第一段階は印刷された文章の読み取り・確認・修正・履歴・出力が対象です。手書き・数式・化学式・表の構造復元は精度保証の対象に含めず、原本を確認できる形にします。ノート取り込み・記憶フラッシュ連携・検索可能PDFは次段階です。

配布用ビルドにはページ・コード・追加requirements・公開ガイドを追加します。個人のOCR原本・履歴・モデルキャッシュ・専用依存を配布物へコピーしません。

参照：[RapidOCR公式](https://github.com/RapidAI/RapidOCR)、[PaddleOCR公式](https://github.com/PaddlePaddle/PaddleOCR)、[pypdfium2公式](https://pypdfium2.readthedocs.io/en/stable/python_api.html)。
