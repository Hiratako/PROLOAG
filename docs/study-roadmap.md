# 学習ロードマップの使い方

1. Study Management → 学習ロードマップを開きます。工程一覧と日程は同じ行で対応し、工程を選ぶと詳細を確認できます。
2. 上部の「工程を追加」から、工程名、期間、予定時間、数量進捗、必要な分類を入力します。割合で記録する場合は「割合（%）」を選び、章・問題数の場合は単位と総量を入力します。
3. 「変更内容を確認」で差分を見て、「この内容で保存」を押します。試験や模試は「試験・節目」で登録します。
4. 前後移動・今日への移動と、週間・4週間・月間・3か月・全体の表示を使い分けます。全体表示の「今日」は4週間表示へ戻ります。科目・教材のまとまりは折りたたみ、工程名・状態・数量進捗を左の一覧から読みます。
5. 工程の詳細から編集・日別タスクとの関連付けへ進めます。新しい日別タスクを作るか、その日の既存タスクを関連付けます。
6. 今日の記録・計画、秒給カウンターで日別タスクを使います。ロードマップに戻り「実績・計画を更新」で最新ログを確認します。

期間バーの幅は開始日〜終了予定日の日数です。数量進捗は `18/40問` のように別に表示し、学習時間から進捗や理解度を自動で増やしません。関連ログ累計には、予定期間より前・後に行った関連学習も含みます。未関連の勉強ログを科目名だけで推定して加算することはありません。

工程の状態（未着手／進行中／完了／保留）と、確定期限超過・終了予定日超過などの日程警告を分けて表示します。保留や進行中の状態を残したまま、確認が必要な日程を把握できます。

関連ログの時間は、日別タスクがない「未連携」、関連タスクはあるが有効なログがない「連携済・記録なし」、記録から集計した時間を区別します。参照が壊れている場合は確認を案内し、未連携を0時間の未学習とは扱いません。予定時間から関連ログ累計を差し引いて、残りに必要な時間とみなすこともありません。

工程・節目を使い終えたら「アーカイブする」で保存します。ガントの「アーカイブ」をオンにすると表示でき、編集画面から解除できます。工程との関連付けを解除しても、日別タスクと学習ログは残ります。

保存競合では確認内容・入力を保持します。「確認を取り消す」で編集へ戻るか、「入力を破棄して再読込」で最新の定義を取得します。後者は未保存入力を破棄します。

編集画面をいったん閉じる場合は「入力を保持して閉じる」を使えます。保持はアプリの記録への保存とは異なります。「入力を破棄して閉じる」は編集中の内容を捨てます。

CSV／ZIP出力の `roadmap_items`、`roadmap_milestones`、`roadmap_allocations` と設定一覧に保存内容を含めます。データ整合性チェックは不正な日付・進捗・参照を検査します。

## ドラッグ編集と一括移動

「工程」表示で「日程を編集」をオンにすると、棒の中央を移動、左右の端で期間を伸縮できます。閲覧と編集で工程名・色・行の対応を変えません。棒にフォーカスして矢印キーで1日、Shift併用で7日動かせます。「矢印キーの操作」で工程移動・開始日・終了日のどれを変えるか選びます。移動中のEscapeは取消です。ドラッグを使わず、工程の編集画面から開始日・終了予定日を入力する方法も使えます。「俯瞰」の棒は閲覧用です。棒を動かす場合は「工程」へ切り替えます。

離すと変更案が表示されます。「日程変更を保存」で確定、「日程変更を取り消す」で戻ります。工程編集の「前提となる工程」を設定すると、前提の終了翌日以降になるよう必要な後続を延期します。前倒しで後続を自動的に詰めません。完了済みの後続に衝突する変更は保存しません。当初予定と変更履歴を保持します。

「表示の補助設定」の「変更前の当初予定を表示」をオンにすると、当初予定と現在の日程が違う工程に破線を表示します。保存前の変更案では、保存済みの日程を点線で示します。破線は当初の計画との比較、点線は今回の変更前との比較です。予定が表示期間と重ならない部分は描画されません。

上部の「一括調整」、または「詳しい操作」の「日程の調整」で複数工程を指定し、±日数の一括移動ができます。後続も同じ日数動かす選択と、前提順序に合わせた案の作成があります。完了・アーカイブ済みは一括移動しません。既存の日別タスクと学習ログは元の日付に残し、割当が工程の期間外になる場合は確認画面で知らせます。

## 工程表示・俯瞰と小さい画面

ガント内の「工程」では、左の名称・状態・数量進捗と、右の日程を同じ行で確認します。プロジェクト・科目・教材のまとまりを折りたたみ、教材・工程名の検索や「要確認だけ」で絞り込めます。前提・後続は選択した工程を中心に確認し、折りたたみ中や表示期間外の参照も詳細からたどれます。「俯瞰」ではプロジェクト・科目ごとにまとめた工程の期間バーと節目を見ます。異なる単位の数量進捗を平均した理解度は表示しません。

検索中は、一致する工程のあるまとまりを開いて表示します。検索のために元の折りたたみ状態は変更しないので、検索を解除すると元の状態へ戻ります。表示期間外にも一致する工程がある場合は検索結果から対象の期間へ移動できます。検索には科目・プロジェクト・要確認・アーカイブの絞り込みも適用されます。目的の工程が見つからない場合は、これらの条件も確認してください。検索や表示期間の移動だけでは記録を保存しません。

全体表示はアーカイブされていない工程・節目の範囲に合わせます。範囲外のアーカイブ工程を詳細からたどる場合は、その工程を確認できる4週間表示へ切り替えます。

工程が多い場合、工程表示は120件ずつ「さらに表示」で追加します。検索は読み込んだ全工程を対象にし、25件ごとのページ切り替えは不要です。俯瞰の期間バーは各グループの先頭120工程までを表示し、件数と制限を明示します。「工程を見る」から工程表示へ切り替えて残りも確認できます。

工程・節目を直接探す場合は「一覧から工程・節目を選ぶ」も使えます。Plotlyは「一覧・Plotlyの補助表示」の「補助のPlotlyを表示」で確認でき、先頭100工程までの期間表示です。工程の選択・編集には主画面または一覧を使います。

狭い画面では工程の一覧と詳細を優先し、PCのガントを読めないほど小さく縮めません。細い棒のドラッグに頼らず、日付入力で編集できます。

## 学習可能時間と日別配分

1. 「学習可能時間・配分」で月〜日の分数と例外日を保存します。0分は休日で、日付別設定を優先します。初期設定は全曜日0分です。
2. 対象期間を選び「負荷を確認・更新」で既存の全日別タスクを含む負荷を確認します。週別グラフは指定期間内の日だけを合計します。
3. 自動配分する工程を選び、「今回追加する時間（分）」を入力して「配分案を作成」を押します。前提関係・工程の期間・確定期限・空き時間を守って配分します。
4. 日別の追加内容と未配分の残り時間を確認し、「配分案を保存」で新しい日別タスクを追加します。配分できた分だけ保存する場合は専用チェックが必要です。

完了・保留・アーカイブ済みには自動配分しません。既に可能時間を超える日には追加しません。前提工程に未配分時間がある場合は後続への配分を保留します。既存タスクは変更しません。入力する時間は追加分なので、同じ時間を別の案で再入力すると追加のタスクになります。

対象は最大366日・100工程・2000タスクです。プレビューと表示だけでは保存しません。保存前に設定と対象全日の日別計画を照合し、競合では案を保持して拒否します。CSV／ZIPには設定済みの場合 `roadmap_capacity` も含めます。

ガント上の「日別配分の負荷を表示」も、登録済みの日別タスク予定と、その日の学習可能時間に基づきます。期間バーの重なりから配分時間を推定しません。学習可能時間を未設定の場合と、明示的に0分とした日は区別します。367日以上の全体表示では負荷を取得せず、表示範囲を短くする案内を表示します。「実績・計画を更新」で日別計画の変更を再取得できます。

## AIで作った計画の一括追加

上部の「AI計画を取り込む」、または「詳しい操作」の「AI計画の取り込み」からmd指示書をダウンロードし、GPT／Geminiへ計画条件と一緒に渡します。AIが返したJSONをアップロードし、分類の対応とガントプレビューを確認して「この計画を追加する」で反映します。画面を開く・ファイルを確認する・プレビューを見る操作では保存しません。

対象は新しい工程と試験・節目です。既存工程の更新・削除、日別タスクや学習可能時間設定の取り込みは行いません。同じ内容の二重追加を検出し、保存前のバックアップと取込履歴を保持します。詳しくは[AI学習計画の取り込み](roadmap-ai-import.md)、AIへの書式指定は[md指示書](ai-roadmap-import-prompt.md)を参照してください。
