# Google Docs 相談レポートと教材の補足情報

確認日: 2026-09-16。Google 側の実アカウント・実 API を使った送信試験は未実施です。回帰テストでは架空データと疑似クライアントを使用しています。初回利用時は、機密情報を含まない内容でプレビューと送信先を確認してください。

## できること・しないこと

学習実績を日次・週次の相談用テキストにまとめ、アプリ専用の Google Docs へ明示操作で送ります。教材の Google リンクと「次はここから」はローカルに保存でき、共有するかはそれぞれ選択します。

- 日次は選択した最終日の 1 日分、週次はその日を含む直近 7 日分です。週次は必ずしも月曜から日曜ではありません。
- 日次用・週次用に専用文書を 1 つずつ作り、以後は同じ文書 URL を使います。日ごと・週ごとに文書を増やす機能ではありません。
- 元の学習記録・教材マスタを書き換えません。Google Docs の編集や GPT の提案を自動で取り込むこともありません。提案を本人が貼り付けて採用する場合は、別機能の [相談提案の取り込み](consultation-proposals.md) を使います。
- 定期送信、双方向同期、自動的な GPT への送信、他人へのアクセス権の付与は行いません。

## 1. Google Docs API を有効にする

初回の Python 追加ライブラリ・Desktop OAuth クライアント・ブラウザ認証・DPAPI 保存の設定は、[Google Sheets 共有の設定ガイド](google-sheets-setup.md) を使用します。Google 用ライブラリは Python 3.11 なら `.deps-google311`、3.12 なら `.deps-google312` に分離し、既存の `.deps311` / `.deps312` に混ぜないでください。

同じ Google Cloud プロジェクトの API ライブラリで、追加で **Google Docs API** を有効にします。[Google Docs の公式 Python クイックスタート](https://developers.google.com/workspace/docs/api/quickstart/python)

OAuth スコープは既存の `https://www.googleapis.com/auth/drive.file` のままです。Docs の新規作成・更新にこのスコープを使用できるため、全ドキュメントや全 Drive への広い権限を追加する必要はありません。Drive API の追加有効化も不要です。[文書作成 API](https://developers.google.com/workspace/docs/api/reference/rest/v1/documents/create)、[文書更新 API](https://developers.google.com/workspace/docs/api/reference/rest/v1/documents/batchUpdate)

すでに接続済みなら、API を有効化した後にアプリの接続状態を確認します。認証が期限切れの場合は既存の接続手順で再認証します。認証 JSON やトークンを相談文・レポート・Git に貼り付けないでください。

## 2. 教材リンクと「次はここから」をローカルに記録する

**10 マスタ管理 → 資料リンク・引き継ぎ** で、教材を選び、**この教材を開く** を押して必要なリンクと再開地点を保存します。同名教材でも教材 ID と所属分類で区別します。保存しただけでは Google へ送りません。

**97 データエクスポート → 資料リンク・引き継ぎ** からも同じ情報を編集できます。

**09 今日の記録・計画** の **次はここから（教材の引き継ぎを表示）** をオンにすると、更新の新しい5件を確認できます。表示だけではデータは保存・変更されません。

- リンクにはタイトルと Google の HTTPS URL を指定します。Google Docs / Sheets / Slides のファイル、Drive のファイル・フォルダへのリンクが対象です。
- 許可された形式の例は `https://docs.google.com/document/d/<ID>/edit`、`https://docs.google.com/spreadsheets/d/<ID>/edit`、`https://docs.google.com/presentation/d/<ID>/edit`、`https://drive.google.com/file/d/<ID>/view`、`https://drive.google.com/drive/folders/<ID>` です。
- HTTP・Google に似せた別ホスト・埋め込みユーザー情報・任意サイトへの転送 URL は受け付けません。URL の形式だけを検査し、リンク先の内容・存在・アクセス権は自動取得しません。
- 「次はここから」には、章・ページ・問題番号や次の作業などを記録できます。内容を事実と誤認しないよう、自分のメモとして扱ってください。
- 保存中に他画面で教材や補足情報が変わった場合は、競合を確認して読み直します。古い表示のまま他の変更を上書きしません。

競合後に入力を残して再開するには、**最新の保存内容との差を確認** を押し、比較を読んで確認チェックを入れ、**入力を保持して最新を再読込** を押します。この操作では保存せず、入力を確認した後で改めて保存します。比較中にさらに更新された場合は、もう一度比較が必要です。他画面で削除されたリンクは勝手に復活させず、除外するか新しいリンクとして追加するかを明示します。削除された教材には保存できません。

保存先は `settings/learning_context.json` です。教材マスタと別に、教材 ID をキーとして保存します。教材を削除した場合も補足情報は自動削除されず、整合性検査で参照切れが「注意」になります。検査でデータを書き換えることはありません。

ローカルの全件 CSV / ZIP エクスポートでは、この補足情報を `settings.csv` に含めます。Google 共有の「含めない」指定はローカル全件エクスポートには適用されません。全件出力を他人へ渡す際は、教材リンク・再開メモも個人情報として確認してください。Google 送信には全件エクスポートを流用しません。

## 3. 相談レポートを確認して送信する

1. **97 データエクスポート** の出力方法で **Google Docs相談レポート** を選びます。
2. 日次または週次と、期間の最終日を選びます。
3. **登録した資料リンクを含める**・**『次はここから』メモを含める** をそれぞれ選び、**資料・引き継ぎメモを共有する教材** で共有する教材を明示的に選択します。初期状態ではどちらも含めません。学習メモなど他の任意項目も共有前に確認してください。
4. **相談レポートのプレビューを作成** を押し、期間・学習時間・教材分類・任意の補足情報・相談文を読みます。元の記録や共有条件を変更した場合は、プレビューを作り直します。未接続でもプレビューと **レポートをテキストで保存** は利用できます。
5. **共有先ドキュメントを作成・確認** を押し、日次または週次の専用 Doc の送信先を開いて確認します。この文書作成だけでは学習データを送りません。任意の既存 Doc の URL を貼り付けて更新することはできません。
6. **このレポートの内容と送信先を確認しました** にチェックし、**Google Docsへ送信** を押します。送る内容は確認済みの固定プレビューです。
7. 成功日時・文書リンク・レポート ID を確認します。必要なら **このレポートを使ってGPTに相談する** から依頼文をコピーします。コピーだけで別サービスへの送信やアクセス権の設定は行われません。

レポートは統計・記録のまとめであり、学習時間だけから理解度や正答率を判断するものではありません。記録がない日も、必ずしも未学習とは扱いません。リンク先の教材本文はレポート生成時に読み取りません。

## 4. 専用 Doc を直接編集しない

日次・週次それぞれの専用 Doc は、次回の共有で本文を置き換える出力先です。履歴を残したい場合や相談の返答・追記を残す場合は、別の文書へコピーして管理してください。

アプリが最後に書いた本文と現在の本文が異なる場合や、未対応の表・画像・ヘッダー等が追加された場合は、上書きを止めます。また、読み取り直後に他の編集が入った場合も文書の版を指定して更新を拒否します。Google API の版指定の仕組みは [WriteControl](https://developers.google.com/workspace/docs/api/reference/rest/v1/documents/batchUpdate#writecontrol) を参照してください。

ただし、文字の装飾だけの変更をすべて検出するものではありません。「編集検出があるから安全に追記できる」とは考えず、専用 Doc には手作業で追記・装飾をしないでください。アプリの管理情報を削除して検査を回避する操作も行わないでください。

## 5. エラー・接続解除

- **Docs API が無効:** OAuth クライアントを作成したプロジェクトで Google Docs API を有効にしたか確認します。権限を広げて回避しないでください。
- **送信が途中で切れた・完了が不明:** **レポート送信済みか確認** を押し、必要なら **同じレポートを再送** します。確認前に新しいプレビューへ切り替えたり、保留中の状態ファイルを削除したりしないでください。
- **文書作成の結果が不明:** 重複文書の作成を避けるため自動再作成を止めます。表示された案内を確認し、Google 側で作成済みの文書がないか確認してください。登録外の文書を自動で上書きすることはありません。
- **手編集を検出:** まず手編集の内容を別文書へ退避し、エラーの内容を確認してください。強制上書きで進める操作はありません。
- **教材情報の形式エラー:** 整合性検査で形式・ID・教材参照・URL・日時を確認し、教材の補足情報を修正してからプレビューを作り直します。追加情報がない従来データも利用できます。

接続解除は PC 内の接続情報・専用文書の登録を削除する操作で、Google 上の日次・週次 Doc や公開済み内容は残ります。未完了の送信を先に確認してください。Google 側のアクセス許可を取り消す手順は [Sheets 設定ガイドの接続解除](google-sheets-setup.md#5-保存先接続解除) を参照してください。既存の Doc を削除したい場合は、Google 側で対象を確認して行います。

認証情報・私的な教材メモ・レポートを含む利用中フォルダは、配布用 ZIP にしないでください。相談時も OAuth JSON・トークン・DPAPI ファイルは共有しないでください。
