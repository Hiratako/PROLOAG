# Web体験版の構成と境界

2026年11月7日の改良。従来の読み取り専用7画面から、Hobbyを除く元25ページ＋案内2ページ＝27ルートへ拡張しています。

## 保持した機能

今日の記録・計画、ロードマップ、秒給カウンター、勉強ログ、学習分析、条件分析、統計演習、学習蓄積、マスタ、ノート、知識都市、カード、復習、日記、服薬、睡眠・体調、運動、生活分析、成分リズム分析、使い方、Google連携の説明、エクスポート、旧版移行、設定、整合性チェック。

Hobbyの3ページは登録しません。Googleの認証・外部送信も公開環境では実行できません。

## 保存先の分離

- `web_demo/sandbox.py` が、サーバーで生成した不透明な識別子と登録済みオブジェクトで一時領域を管理します。URLや入力欄から保存先を選べません。
- ContextVarとStreamlitのSessionStateで呼び出し元の保存先を解決します。共有のROOTや設定を訪問者ごとに書き換えません。
- 既存のimport済みパス・デフォルト引数は `config.ContextPath` で解決します。コードと文書の参照には固定のSOURCE_ROOTを使います。
- ページと部分更新の実行に訪問者コンテキストを付けます。Matplotlibを含むページ描画はロックで保護します。
- JSONの読み書きは字句上・解決後の両方で専用領域内へ制限します。他の訪問者、共通サンプル、リンク経由の逸脱を拒否します。
- 訪問者未準備時は保存・ロック・バックアップ・復旧を拒否します。`WEB_DEMO_READ_ONLY=True` はこの失敗時の保護として残ります。

## 上限と寿命

一時領域は1訪問者24MiB・4,000ファイル、1回のJSON/ステージ合計2MiB、同時32領域を上限とします。ロックファイル作成も容量・件数を検査します。使用中の領域の削除は処理完了まで延期します。

稼働プロセスで把握している領域は、2時間利用されなければ新規体験開始時等に回収します。突然のプロセス終了後に残ったOS一時ファイルまで2時間で確実に消す保証はありません。OSやCloud側の一時領域のライフサイクルにも依存します。

これは個人記録の永続保存サービスではありません。認証、永続DB、個人情報の管理を備えた本番の複数利用者向けサービスとは区別します。

## 日付と機能差

基準日は2026年11月5日です。タイマーの開始・終了も基準日に合わせ、保存したセッションが同日の計画・分析へ反映されるようにしています。経過時間の計測は従来どおり単調増加時計を使います。

元の715 JSONは独立再生成で一致を確認した架空データです。インポート・入力・ダウンロードも体験用サンプルで試してください。
