# PROLOAG v0.1.0-preview.3

Windowsローカル版に「録音・文字起こしメモ」を追加しました。

- 最大3時間のPC録音、一時停止・再開、上限での自動停止。
- 録音中の分割保存と、保存済み音声からの中断復旧。
- 文字起こし、全文編集、TXT保存、認識原文の時刻付きTXT。
- 認識が中断した場合の完了済み区間の再利用、最大60秒の部分再生。
- 従来の10分までのブラウザ簡易録音も利用できます。

## 配布ファイル

- **通常版**：`proloag-v0.1.0-preview.3-windows-x64.zip`。記録が空の状態から始めます。
- **Demo版**：`proloag-demo-consultant-v0.1.0-preview.3-windows-x64.zip`。2026年11月5日を基準にした架空180日分とサンプル計画を収録しています。録音の実データは含めません。

各ZIPの`.sha256`と`SHA256SUMS-proloag-v0.1.0-preview.3.txt`も添付します。

## 準備と利用

Windows x64向け、Python 3.11.4同梱です。初回の基本ライブラリ導入にはインターネット接続が必要です。録音ライブラリと文字起こしエンジン・モデルは任意の追加導入です。録音・保存だけなら文字起こしエンジンは不要です。[録音の準備・使い方](https://github.com/Hiratako/PROLOAG/blob/v0.1.0-preview.3/docs/audio-memos.md)を確認してください。

既存の利用フォルダへ上書きせず、新しいフォルダへ展開してください。公開済みのpreview.2は保持します。Web体験版は従来の構成のままで、録音機能を含めません。

録音中はブラウザを閉じてもPROLOAG本体が動いていれば録音を継続します。終了するときは「録音を停止して保存」を押してください。PCの再生音を直接録音する方式ではありません。

## 検証範囲

関連テストと、合成音声による3時間相当の保存・結合・再生、別プロセスの停止・中断保存を検証しています。録音用ライブラリは、未導入の配布用Pythonからの初回セットアップ・再実行を確認しました。

詳しい集計・実行環境・確認範囲は[検証記録](https://github.com/Hiratako/PROLOAG/blob/v0.1.0-preview.3/docs/verification-audio-memos.md)を参照してください。

実マイクでの3時間連続耐久試験、別のWindows端末での初回導入、実際のGoogle認証・送信は未実施です。録音はマイク・ドライバ・PCの負荷に依存するため、短い試し録音で入力レベルと保存結果を確認してください。[既知の制限](https://github.com/Hiratako/PROLOAG/blob/v0.1.0-preview.3/docs/known-limitations.md)も参照してください。
