# PROLOAG v0.1.0-preview.4

Windows x64の通常版とDemo版に、メディア変換・文字起こし・画像とPDFの読み取りの更新を反映しました。

- **MKV**を直接文字起こしできます。MKV→MP4には映像を保持する方式と、互換性を重視してH.264／AACに変換する方式があります。
- **音声・動画と録音メモ**でlarge-v3とturboを選べます。CPUが初期設定です。対応環境ではGPUを利用でき、続行できなくなった場合は、完了した区間を保持して同じモデルでCPUへ切り替えます。
- **画像・PDF**に高精度OCRを追加しました。文字層と画像が混在するPDFでは、既存の文字と画像内の文字をまとめて読み取ります。

## ダウンロード

- **通常版**の `proloag-v0.1.0-preview.4-windows-x64.zip` は、記録が空の状態から使う版です。
- **Demo版**の `proloag-demo-consultant-v0.1.0-preview.4-windows-x64.zip` は、2026年11月5日を基準にした架空180日分のデータとサンプル計画を収録します。

各ZIPの `.sha256` と、まとめた `SHA256SUMS-proloag-v0.1.0-preview.4.txt` も添付します。ZIPは新しい書き込み可能なフォルダーへ展開し、最初に `README_FIRST.md` をお読みください。既存環境から移行するときの手順は同梱の `UPDATE_GUIDE.md` にあります。

## 準備と検証範囲

Python 3.11.4 x64を同梱しています。初回の基本ライブラリ導入にはインターネット接続が必要です。FFmpeg／FFprobe、録音・文字起こし・OCRの専用依存、認識モデル、GPU用DLLは、利用する機能に応じて追加で準備します。[メディア変換](https://github.com/Hiratako/PROLOAG/blob/v0.1.0-preview.4/docs/media-conversion.md)・[文字起こし](https://github.com/Hiratako/PROLOAG/blob/v0.1.0-preview.4/docs/transcription.md)・[OCR](https://github.com/Hiratako/PROLOAG/blob/v0.1.0-preview.4/docs/ocr.md)の手順を参照してください。

ZIPの収録内容と配布ページの検証結果は、同梱の `RELEASE_MANIFEST.json` に記載します。文字起こしとOCRの動作確認には合成音声と合成教材を使用しました。認識結果は素材、選んだモデル、PC環境によって変わります。
