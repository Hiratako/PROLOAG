# PROLOAG v0.1.0-preview.5

Windows x64の通常版とDemo版に「ざっくり記録」と、学習記録・復習の修正を反映しました。

## 変更点

- 「勉強ログ → ざっくり記録」から、週の日ごとに内容を入力したり、指定期間に1日あたりのおおよその学習時間を記録したりできます。週まとめでは学習時間を空欄にして内容だけを残せます。
- 別タブで異なる曜日を編集すると両方の下書きが残ります。同じ曜日の編集が重なると入力を保持して確認を促します。前週からコピーした行を空欄に戻しても、ほかの曜日を保存できます。
- 削除した学習タスクのIDが再利用されて過去ログに別のタスク名が表示される問題と、古い画面から復習結果を送信して次回分まで消化される問題を修正しました。
- ホームの「今日の勉強時間」にざっくり記録を含めます。学習蓄積ビジュアライザーの週別CSVは、勉強ログと同じ月曜始まりで集計します。通常記録だけの期間では従来のCSVの列構成を維持します。

## ダウンロード

- **通常版**の `proloag-v0.1.0-preview.5-windows-x64.zip` は、記録が空の状態から始める版です。
- **Demo版**の `proloag-demo-consultant-v0.1.0-preview.5-windows-x64.zip` は、2026年11月5日を基準にした架空180日分のデータとサンプル計画で入力や分析を試せます。

各ZIPの `.sha256` と、まとめた `SHA256SUMS-proloag-v0.1.0-preview.5.txt` を添付します。ZIPは新しい書き込み可能なフォルダーへ展開し、`README_FIRST.md` をお読みください。既存環境から記録を移すときは `UPDATE_GUIDE.md` を参照してください。

## 準備と検証範囲

Python 3.11.4 x64を同梱しています。初回の基本ライブラリ導入にはインターネット接続が必要です。録音、変換、文字起こし、OCR、Google連携は、利用する機能に応じて追加準備が必要です。

配布物の内容と検証結果は、同梱の `RELEASE_MANIFEST.json` に記載しています。
