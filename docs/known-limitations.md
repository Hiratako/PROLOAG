# 既知の制限と確認範囲

この公開ソースは、Windows向け`0.1.0-preview.1`を基礎に、公開済みのWindows版`0.1.0-preview.2`に向けて成分初期例・Demo生成内容・利用条件と案内を調整しました。以下のアプリ挙動は、これらの成分初期例・利用条件の変更では修正していません。

## 記録と表示

- 睡眠・体調の未記録日に、入力初期値がサマリーへ表示される場合があります。
- 手動学習ログでは未操作のコンディション初期値も保存されます。条件欄を確認して保存してください。
- 同じ日の睡眠・体調を複数画面から並行編集すると、未保存入力が保持されないケースがあります。保存後の内容を確認してください。
- 一部の自動計算表示は、入力直後には追随せず、保存時に再計算されます。
- 設定の初期時給0・初期運動時間0は別の初期値で再表示される場合があります。不正な時刻が既定値に置き換わる場合もあります。
- ノートのMarkdown出力は保存済み版です。変更を出力へ含める場合は、先にノートを保存してください。
- 保存済みカードや運動記録には、画面からの編集操作が十分そろっていません。

## 計画・分析

- ロードマップの俯瞰は多数の並行工程で縦に長くなります。複数段の期限マーカーは対象が分かりにくい場合があるため、工程の詳細日付も確認してください。
- ページをまたぐ日付・タスク・期間等の引き継ぎが一部未対応です。
- 学習時間・件数は理解度や習得度そのものではありません。条件比較は記録上の関連であり、因果や健康状態を確定する機能ではありません。

## 実行と保存

- 基本依存の固定定義はWindows x64 / Python 3.11で確認した構成です。ほかのOSやPython版の検証は別途必要です。
- Google、FFmpeg、文字起こし/OCRの任意依存・モデルは基本依存と分けて導入します。
- 保存はプロジェクト内のローカルファイルです。公開サーバーの認証・利用者間データ分離は実装されていません。
- CSV・ZIP出力は一覧・分析用で、アプリ全体を一括復元するバックアップ形式ではありません。
- ソース起動とWindows配布ランチャーは別の準備手順です。使用中のポートで別のサーバーを勝手に終了する操作は行いません。

この一覧は、機能追加や修正予定の確約ではありません。変更時は、対象ケースのテスト・文書・版をそろえて更新します。
