# 音声・動画の文字起こし

Hobby & Tools → **音声・動画の文字起こし** で、MP4／MP3を日本語・英語の文章へ変換します。

## 使い方

1. 200MBまでのファイルをアップロードするか、PC内のファイルのフルパスを入力します。
2. **音声を確認** を押し、音声トラックを選びます。入力変更や言語選択だけでは確認・認識を始めません。
3. 日本語／英語／自動判定、標準／精度優先、任意の用語ヒントを選び、**文字起こしを開始** を押します。
4. 進捗と経過時間を確認します。モデルの準備中は進捗率が動かない場合があります。別ページへ移動しても処理は続きます。
5. 完了後は時刻で区間を選び、**この区間を聞く** で音声を確認し、文章を修正して **修正を保存** を押します。
6. 保存済み結果をTXT／SRT／VTT／JSONで取得します。ダウンロードで認識は再実行しません。

標準はmultilingual small、精度優先はmultilingual mediumです。自動判定は各処理区間冒頭の音声を参考にします。日英混在・固有名詞・雑音・重なった発話では修正が必要なことがあります。用語ヒントは認識の参考情報で、確定の置換辞書ではありません。翻訳・話者分離・要約・ノートへの自動登録は含みません。

区間の聞き直しは選択した開始時刻から最大60秒分だけを読み出します。原文と時刻を保持して文章だけを修正し、字幕出力は保存済みの修正を使います。JSONには原文・修正後・時刻・処理状態・修正バージョンが残ります。TXTはExcel等でも読みやすいUTF-8 BOM付き、SRT／VTT／JSONはUTF-8です。

## 初回セットアップ

既存のメディア変換と同じFFmpeg／FFprobeを使います。追加でfaster-whisper 1.2.1が必要です。ページの「文字起こしエンジン・保存場所」に、起動中アプリと同じPythonを使うPowerShellコマンドを表示します。

```powershell
& '<アプリの起動用python.exe>' -B '<アプリの場所>\app_core\setup_transcription.py'
```

専用の `.deps-asr311`（Python 3.11の場合）へ導入し、アプリ全体の `.deps311` と分けます。認識エンジンは別プロセスだけで読み込み、Streamlit側へ追加のNumPy等を混ぜません。配布先でも必要時に同じセットアップを使います。

モデルは最初にその認識モードを実行したとき、公開配布元から `tools/asr-models` へダウンロードします。標準モデルは約0.5GB、精度優先は約1.5GBです。取得済みのモデルを優先して使い、認識はPC内で行います。音声を外部APIへ送信する処理はありません。

初期値はCPU/int8です。高度な設定のGPU試行は対応するCUDA・cuDNNがある場合向けで、初期化に失敗した場合はCPUへ戻します。開発時の実音声確認はCPUで行っています。

## 保存と中止

- 文字起こし履歴・原文・修正・聞き直し用音声は `transcription_data/jobs/<ID>/` に保存します。ページを開くだけでは作成しません。
- 元のローカルMP4／MP3は変更しません。アップロード入力は履歴専用領域にコピーします。
- 聞き直し用に16kHz・モノラルのWAVを保持するため、1時間あたり約115MBを使います。アップロード時は入力コピー分の容量も使います。
- **文字起こしを中止** で停止できます。モデル取得中・認識中の処理も別プロセスで終了でき、保存済みの区間は残ります。音声準備中はFFmpegを終了してから停止します。
- 中止／失敗／プロセス終了後は、途中結果である旨を表示して、認識できた区間だけを出力できます。元ファイルを指定し直して新しい履歴として再実行します。未処理区間からの自動再開は行いません。
- 完了履歴はブラウザー再読込やアプリ再起動後も残ります。アプリを止めても処理プロセスは独立して続行します。PC終了等でプロセスがなくなった場合は中断として表示します。
- 未保存の文章修正はブラウザーのセッション中に保持します。ブラウザー再読込・アプリ再起動前に修正を保存してください。別画面との修正競合では入力を保持して保存を止めます。
- 履歴削除は、その履歴の音声・原文・修正を削除します。元のローカルファイルは削除しません。実行中は削除できません。

## 処理と配布

同時に実行できる文字起こしは1件です。開始操作は処理IDで重複実行を防ぎ、結果を1区間ずつディスクへ反映します。長時間音声は5分単位・前後2秒の重なりを使って認識し、区間の元時刻へ戻します。境界付近の文章は聞き直して確認できます。入力は長さを確認できる24時間以内の音声が対象です。

履歴用の独立したロックとatomic replaceを使い、学習記録の `backups/json_operations` ロックは取得しません。音声の全体をメモリへ載せず、認識用の区間と聞き直し用の短い音声だけを読み出します。

配布スクリプトはページ・コード・公開ガイド・追加requirementsだけを含めます。個人の文字起こし履歴、認識モデル、追加ライブラリのキャッシュを配布物へコピーしません。既存ZIPの更新は別作業です。

参照：[faster-whisper公式](https://github.com/SYSTRAN/faster-whisper)、[認識処理の公式実装](https://github.com/SYSTRAN/faster-whisper/blob/master/faster_whisper/transcribe.py)。
