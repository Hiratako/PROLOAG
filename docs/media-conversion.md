# メディア変換：MP4 → MP3

Hobby & Tools → メディア変換から使います。ローカルPCで変換するため、外部サービスへの送信やAPIキーは不要です。

1. 「アップロード」でMP4を選ぶか、「PC内のファイルを直接指定」で動画のフルパスを入力します。エクスプローラーの「パスのコピー」の引用符はそのまま貼れます。アップロードは200MBまで、大容量動画は直接指定を使います。
2. 「動画を確認」で長さ・サイズ・音声トラックを取得します。別の動画を指定した場合は、再度確認して対象を切り替えます。
3. 変換する音声と言語を選び、音質を軽量128／標準192／高ビットレート320kbpsから選びます。元動画を超える音質改善はありません。3ch以上はステレオへ変換します。
4. 「MP3に変換」で開始します。進捗・経過時間を確認し、必要なら「変換を中止」を押します。別のページへ移動して戻っても同じセッションなら状態を確認できます。
5. 完了後、MP3の長さ・容量・使用した音声を確認します。保存名を変える場合は入力して「保存名を適用」を押し、「保存する名前」を確認します。64MB以内なら試聴・ダウンロードできます。
6. 「PCへ直接保存」では既存の保存先フォルダーをフルパスで入力します。大きな結果はこの方法で保存します。同名ファイルは上書きしないため、必要なら別名を指定します。
7. 使い終えたら「結果・一時ファイルをクリア」。元動画と、すでにPCへ保存したMP3は残ります。

同時に実行できる変換は1件です。設定変更・ダウンロード・ページ表示だけでは変換しません。動画を確認した後に元動画を変更した場合は確認し直してください。中止・失敗後は同じ確認済み動画から再試行できます。

変換結果は一時データです。アプリを終了する前に必要なMP3を保存してください。ブラウザ更新で別セッションになった場合、前の一時結果に戻れないことがあります。通常終了・明示クリアで削除し、24時間未利用の結果は同じプロセスの次回メディア利用時にも片付けます。異常終了時にはOSの一時領域に残ることがあります。

## FFmpegの準備

FFmpegとFFprobe、およびMP3エンコーダー `libmp3lame` を含む構成を使用します。

- 同梱する場合：アプリの `tools/ffmpeg/bin/ffmpeg.exe` と `ffprobe.exe`。
- 任意のフォルダーに置く場合：`PROLOAG_FFMPEG_DIR` を実行ファイルのフォルダー、またはその親フォルダーへ設定します。
- PCへインストール済みの場合：PATHのFFmpegとFFprobeを使います。

ページ下部「変換エンジンの確認・セットアップ」で検出先を確認できます。Windowsでは補助プロセスの黒いウィンドウを出さずに処理します。

配布用ビルドに同梱する場合は、既存のビルド引数に `-FFmpegDirectory 'C:\ffmpeg-8.0-essentials_build'` を追加します。単体で動くWindowsビルドを指定し、付属の `LICENSE` または `LICENSE.txt` も必要です。指定された2実行ファイルとLICENSEだけをコピーします。指定を省略した配布版では受け取ったPCの環境に応じてエンジンを用意します。

この第1段階は1本ずつの全区間変換です。区間切り出し、一括変換、音量調整は今後の追加対象です。
