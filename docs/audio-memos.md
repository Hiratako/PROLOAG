# 録音・文字起こしメモ

Hobby & Tools → **録音・文字起こしメモ** で、録音をPCへ保存し、後から文字起こし・全文編集・TXT保存を行います。Windowsで動かすローカル版の機能です。

## 使い方

1. **長時間録音（PC）** で入力機器を確認し、録音を開始します。
2. 必要なら一時停止・再開します。話し終えたら **録音を停止して保存** を押し、メモへの取り込み完了を確認します。
3. 保存された録音メモで **文字起こし** を押します。初期値は日本語・標準です。
4. 認識結果を確認して全文を編集し、**メモを保存** を押します。
5. 保存済みの全文TXT、または認識原文の時刻付きTXTを取得します。履歴から後日開き直せます。

録音は、PROLOAGを動かしているWindows PCのマイクを使用します。PCの再生音を直接取得する方式ではありません。録音中に文字を逐次表示する機能もありません。

## 長時間録音の初回準備

録音用ライブラリは基本環境・認識環境から分けて導入します。Python 3.11ではアプリ内の `.deps-record311` を使用します。初回の取得にはインターネット接続が必要です。

ソース版は、アプリを起動するPythonで実行します。

```powershell
.\.venv\Scripts\python.exe app_core/setup_recording.py
```

Windows版ZIPは一度通常起動して基本ライブラリの準備を終え、アプリを終了します。展開フォルダでPowerShellを開き、同梱Pythonを使用します。

```powershell
$env:PYTHONPATH = (Resolve-Path .\app\.deps311).Path
& .\runtime\python311\python.exe -B .\app\app_core\setup_recording.py
```

アプリ内の **PC録音の準備・保存場所** にも起動中のPythonに対応する案内を表示します。録音ライブラリを基本環境の `PYTHONPATH` へ手動追加する必要はありません。セットアップ・機器一覧確認・ページ表示だけでは録音を始めません。Windowsのマイク権限は利用者が設定します。

文字起こしには別途[文字起こしの準備](transcription.md)が必要です。FFmpeg／FFprobe、認識エンジン、モデルを使用します。録音・保存だけなら認識エンジンは不要です。認識はPC内で行い、外部AI APIへ音声を送信しません。初回のモデル取得等にはネット接続が必要です。

## 録音時間と終了方法

PC録音は、録れた音声の累計で1回 **3時間まで** です。一時停止中の時間は含めず、上限に達すると保存して自動停止します。16kHz・モノラル・16bit PCMを、2秒のチェックポイントと60秒単位のWAVで順次保存します。

専用プロセスで録音するため、ページ移動・再読み込み・ブラウザ終了後も、PROLOAG本体が動いていれば継続します。終了するときは **録音を停止して保存** を押してください。アプリ本体の終了を検出した場合も保存して停止しますが、重要な録音では先に画面で保存完了を確認してください。

録音中だけ自動スリープを抑止する設定があります。手動スリープ、ふたを閉じる操作、電源断は防げません。マイク切断、入力欠落、保存容量不足、PCのスリープ等を検出した場合は中断して保存済み音声を保持します。確定前の末尾は可能な範囲で復旧します。完全な無損失を保証する機能ではありません。

3時間の原音は約346MBです。分割音声と結合したメモ用WAVの両方を保持し、認識時には作業用音声も使用するため、十分なディスク空き容量を用意してください。

従来の **簡易録音（ブラウザ・10分まで）** も使用できます。こちらは停止後に受信したWAVを検査する方式で、10分での自動停止・録音中の順次保存は行いません。1回10分・64MiBまでです。録音中はページを開いたままにしてください。

## 保存先と復旧

- `transcription_data/recordings/<ID>/`：分割音声、途中のPCM、録音台帳、状態、workerログ。
- `transcription_data/memos/<ID>/`：結合WAV、録音メモ、認識原文、編集本文、全文TXT。
- `transcription_data/jobs/<ID>/`：認識区間、修正、進捗、再開チェックポイント等。

タイトルを変更しても保存先IDは変わりません。停止・中断後は、形式・順序・ハッシュを検証した区間をメモ用WAVへ結合します。元の分割音声は保持します。取り込みに失敗した場合は、履歴の **保存済み音声をメモへ取り込み直す** から再試行できます。同じ録音の再取り込みで編集済み本文を上書きしません。

同じ音声・設定で失敗・中止した認識を再試行すると、検証できた完了済み5分区間を再利用します。未完了区間は再認識します。設定を変更した場合や、完了結果をもう一度認識する場合は最初から処理します。

長い音声は開始位置を指定して最大60秒ずつ再生します。時刻付きTXTは認識原文と元音声の時刻を示します。編集した全文へ時刻を付け直すものではありません。手動編集した本文は再認識で上書きしません。

全文TXTは保存済みの本文から生成します。TXTだけの更新に失敗した場合は画面に状態を表示し、**TXTを作り直す** で再生成できます。未保存の編集はダウンロードへ含みません。

これらの保存先には音声や私的な文章が含まれます。使用中のフォルダ全体をGitへ登録・再配布しないでください。公開ソースと未使用の配布ZIPには、実録音・認識結果・認証情報・導入済みライブラリ・モデルを含めません。

## 対応範囲と検証

PC録音はWindows x64／Python 3.11を検証基準にしています。公開Web体験版にはこの機能を含めません。

合成PCM、疑似入力、別プロセスの検証で上限・分割保存・一時停止・再開・親終了時保存・中断復旧を確認しています。3時間相当の音声を使う加速検証は、実マイクの3時間連続耐久試験とは異なります。実マイクの3時間連続試験は未実施です。個別のマイク・ドライバ・PC負荷による動作差は、短い試し録音で確認してください。
